# Icon Files Needed

Place the following icon files in this directory:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)  
- icon128.png (128x128 pixels)

You can create simple icons using any image editor or online icon generator.
The icons should represent a clock or timer to match the extension's purpose.

For now, you can use placeholder images or create simple colored squares with text "RT" (Raid Tracker).
